
# Context Compression Lab

A small web app that compresses text in two ways:

- **Remove duplicate lines** — removes repeated lines while keeping their original order.
- **AI summary** — uses a local Phi-3 model through Ollama to create a shorter summary.

The app has a Go backend and a simple HTML, CSS, and JavaScript frontend.

## Features

- Text input and compression-method selection
- Character counts and percentage reduction
- Local AI summarization with Ollama
- API error handling
- Automated Go tests

## Requirements

- Go installed
- [Ollama](https://ollama.com/) installed for AI summaries
- Phi-3 downloaded in Ollama

Download the model with:

```powershell
ollama pull phi3:latest
```

## Run locally

1. Start Ollama and make sure the Phi-3 model is available.
2. In the project folder, start the app:

   ```powershell
   go run .
   ```

3. Open [http://localhost:8080](http://localhost:8080) in your browser.
4. Paste text, select a compression method, and click **Compress text**.

The duplicate-line method does not require the AI model. The AI-summary method does.

## Run tests

```powershell
go test ./...
```

## API

`POST /api/compress`

Example request:

```json
{
  "text": "A line of text.\nA line of text.",
  "method": "duplicate-lines"
}
```

Available methods:

- `duplicate-lines`
- `ai-summary`

The response includes the compressed text, character counts, reduction percentage, and selected method.

## Note

AI summaries are generated by a local model and may occasionally be longer than the input or omit details. Review the result before relying on it.
